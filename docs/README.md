# 文档导航（精简版）

本文档用于减少重复内容阅读，明确每份文档的唯一职责。

## 一、主文档（优先阅读）

1. [方案设计.md](方案设计.md)
- 职责：需求边界、器件方案取舍、系统级目标。
- 不承载：任务级实现细节、调度机制细节。

2. [软件架构设计.md](软件架构设计.md)
- 职责：软件分层、任务设计、调度与并发、状态机与持久化。
- 对应 HTML 版： [软件架构设计.html](软件架构设计.html)

3. [模块接线与控制细化.md](模块接线与控制细化.md)
- 职责：硬件接线、引脚映射、执行器落地接入建议。
- 不重复：整体需求背景（见方案设计）。

4. [联调与验收测试清单.md](联调与验收测试清单.md)
- 职责：测试流程与验收项。

## 二、发布与归档文档

1. [V1发布清单.md](V1发布清单.md)
- 职责：版本冻结、发布留档。

2. [物料清单.md](物料清单.md)
- 职责：BOM 与采购信息。

## 三、推荐阅读路径

1. 方案设计 -> 确认目标与约束。
2. 软件架构设计 -> 明确任务与调度。
3. 模块接线与控制细化 -> 对齐硬件接口。
4. 联调与验收测试清单 -> 执行验证。
5. V1发布清单 -> 版本发布归档。

## 四、维护约定（避免重复）

1. 需求/方案变化只改 [方案设计.md](方案设计.md)。
2. 任务/调度变化只改 [软件架构设计.md](软件架构设计.md)。
3. 引脚/接线变化只改 [模块接线与控制细化.md](模块接线与控制细化.md)。
4. 测试项变化只改 [联调与验收测试清单.md](联调与验收测试清单.md)。

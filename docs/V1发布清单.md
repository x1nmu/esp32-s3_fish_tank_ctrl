## 3. 固件构建

### 3.1 推荐构建方式（ASCII 镜像）

在 firmware/esp32_idf 目录执行：

1. Set-ExecutionPolicy -Scope Process Bypass -Force
2. .\\tools\\build_ascii.ps1 -Action build

### 3.2 原生命令方式

在 firmware/esp32_idf 目录执行：

1. idf.py set-target esp32s3
2. idf.py build

### 3.3 构建验收

- [ ] 构建日志包含：Project build complete

## 4. 烧录与启动验证

在 firmware/esp32_idf 目录执行：

1. idf.py -p COM16 flash
2. idf.py -p COM16 monitor

启动日志检查：

- [ ] 出现项目名：fish_tank_controller_idf
- [ ] 出现应用启动日志：Booting fish tank controller (ESP-IDF)
- [ ] WiFi 逻辑正常（STA 成功或 AP 回退）
- [ ] Web 服务正常启动
- [ ] 无阻断性崩溃（panic/reboot loop）

# 100L 鱼缸温度控制器系统连接图

```mermaid
flowchart LR
    P5[5V 控制电源] --> ESP[ESP32-S3-DevKitC-1\n16MB Flash + PSRAM]
    P5 --> RELAY[2 路继电器模块]
    P5 --> BUZ[蜂鸣器模块]

    ESP -->|3.3V| T1[DS18B20-A]
    ESP -->|3.3V| T2[DS18B20-B]
    ESP -->|I2C SDA/SCL| OLED[1.3 OLED SSD1306]
    ESP -->|GPIO15| BUZ
    ESP -->|GPIO19| RELAY
    ESP -->|GPIO18| RELAY
    ESP -->|GPIO12/13/14| KEY[SET/UP/DOWN 按键]
    ESP -->|GPIO8/9| OLED

    T1 -->|GPIO4| ESP
    T2 -->|GPIO16| ESP

    RELAY --> HEATER[加热棒]
    RELAY --> COOLER[风扇或冷水机]

    MAINS[交流电源] --> RELAY
    RELAY --> HEATER
    RELAY --> COOLER
```

## 说明

- 该图用于快速查看模块连接关系。
- 详细电气连接以 [原理图设计.md](%E5%8E%9F%E7%90%86%E5%9B%BE%E8%AE%BE%E8%AE%A1.md) 和 [接线总表.md](%E6%8E%A5%E7%BA%BF%E6%80%BB%E8%A1%A8.md) 为准。
- 第一版默认加热和制冷都采用继电器控制。
- 当前固件默认目标平台为 ESP32-S3-DevKitC-1，I2C OLED 与按键引脚已按 S3 版本固定。

# 100L 鱼缸温度控制器原理图实施稿（交流负载版 V1）

本文件用于直接指导在 AD 或 EasyEDA 中绘制第一版原理图。

## 1. 图纸结构

建议采用 5 张子页：

- S1 电源与保护
- S2 主控与传感器
- S3 显示与按键
- S4 执行器控制（继电器）
- S5 端子与接口

## 2. 全局网络名（先建网）

- +5V_CTRL
- +3V3
- GND
- TEMP_A
- TEMP_B
- I2C_SDA
- I2C_SCL
- HEAT_CTRL
- COOL_CTRL
- BUZZ_CTRL
- AC_L_IN
- AC_N_IN
- AC_HEAT_L_OUT
- AC_HEAT_N_OUT
- AC_COOL_L_OUT
- AC_COOL_N_OUT

## 3. 位号冻结（首版）

- U1 ESP32-S3-DevKitC-1
- U2 DS18B20-A
- U3 DS18B20-B
- U4 OLED SSD1306 1.3 寸 I2C
- R1 4.7k（TEMP_A 上拉）
- R2 4.7k（TEMP_B 上拉）
- SW1 SET
- SW2 UP
- SW3 DOWN
- K1 Heat Relay（IN1）
- K2 Cool Relay（IN2）
- BZ1 有源蜂鸣器
- F1 控制电源保险丝
- F2 加热支路保险丝
- F3 制冷支路保险丝
- MOV1 交流压敏
- TS1 独立温控开关
- TF1 热熔断器
- J1 控制电源输入（2P）
- J2 探头接口（4P）
- J3 加热负载接口（2P）
- J4 制冷负载接口（2P）
- J5 按键扩展接口（4P）

## 4. 分页连线清单

### 4.1 S1 电源与保护

- J1-1 -> F1 -> +5V_CTRL
- J1-2 -> GND
- +5V_CTRL -> U1-VIN（或 5V）
- +5V_CTRL -> K1-VCC
- +5V_CTRL -> K2-VCC
- +5V_CTRL -> BZ1-VCC（若模块需要）
- U1-3V3 -> +3V3
- AC_L_IN 与 AC_N_IN 进入交流侧保护区
- AC_L_IN 与 AC_N_IN 之间并联 MOV1

### 4.2 S2 主控与传感器

- U1-GPIO4 -> TEMP_A
- U1-GPIO16 -> TEMP_B
- U2-DQ -> TEMP_A
- U3-DQ -> TEMP_B
- R1: TEMP_A -> +3V3
- R2: TEMP_B -> +3V3
- U2-VDD/U3-VDD -> +3V3
- U2-GND/U3-GND -> GND

### 4.3 S3 显示与按键

- U1-GPIO8 -> I2C_SDA
- U1-GPIO9 -> I2C_SCL
- U4-SDA -> I2C_SDA
- U4-SCL -> I2C_SCL
- U4-VCC -> +3V3
- U4-GND -> GND
- U1-GPIO12 -> KEY_SET（SW1 另一端接 GND）
- U1-GPIO13 -> KEY_UP（SW2 另一端接 GND）
- U1-GPIO14 -> KEY_DOWN（SW3 另一端接 GND）

### 4.4 S4 执行器控制（继电器）

- U1-GPIO19 -> HEAT_CTRL -> K1-IN1
- U1-GPIO18 -> COOL_CTRL -> K2-IN2
- U1-GPIO15 -> BUZZ_CTRL -> BZ1-IN（或三极管驱动级）
- K1-GND/K2-GND -> GND

交流功率链路：

- AC_L_IN -> F2 -> TS1 -> TF1 -> K1-COM
- K1-NO -> AC_HEAT_L_OUT
- AC_N_IN -> AC_HEAT_N_OUT
- AC_L_IN -> F3 -> K2-COM
- K2-NO -> AC_COOL_L_OUT
- AC_N_IN -> AC_COOL_N_OUT

### 4.5 S5 端子与接口

- J2-1=+3V3
- J2-2=TEMP_A
- J2-3=TEMP_B
- J2-4=GND
- J3-1=AC_HEAT_L_OUT
- J3-2=AC_HEAT_N_OUT
- J4-1=AC_COOL_L_OUT
- J4-2=AC_COOL_N_OUT
- J5-1=KEY_SET
- J5-2=KEY_UP
- J5-3=KEY_DOWN
- J5-4=GND

## 5. 绘制顺序（建议）

1. 先放置 U1、J1、J2、J3、J4、J5 并建立全局网络名
2. 完成 S2/S3 低压功能链路（传感器、OLED、按键）
3. 完成 S4 控制信号到继电器输入
4. 最后绘制交流功率链路和保护器件
5. 执行 ERC，确保交流与低压网络无误连

## 6. 首次审图必查项

- TEMP_A/TEMP_B 不可短接，不共总线
- OLED 电源固定 +3V3
- HEAT_CTRL 与 COOL_CTRL 不可对调
- AC 侧仅切火线，零线直通
- TS1 与 TF1 已串在加热链路
- 交流区和低压区图纸边界明确

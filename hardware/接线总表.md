## 4. 交流负载接线

### 4.1 加热器

| 线路 | 连接方式 |
| --- | --- |
| AC_HEAT_L | 市电火线 -> K1 COM -> K1 NO -> 加热棒火线 |
| AC_HEAT_N | 市电零线 -> 加热棒零线 |

### 4.2 制冷器

| 线路 | 连接方式 |
| --- | --- |
| AC_COOL_L | 市电火线 -> K2 COM -> K2 NO -> 制冷器火线 |
| AC_COOL_N | 市电零线 -> 制冷器零线 |

## 5. 布线注意事项

- 双 DS18B20 探头线尽量避开继电器和交流负载线
- OLED I2C 线尽量短，避免与强干扰回路并行
- 加热和制冷交流线与主控低压区分区布线
- 继电器输出端子与控制板之间保留安全间距
- 若控制板自制 PCB，高压与低压部分必须明确隔离区域

## 6. 第一版接线结论

第一版先按以下方式实施：

- 主控固定采用 ESP32-S3-DevKitC-1，16MB Flash，启用 PSRAM
- 双探头独立 GPIO 接法
- OLED 走 I2C
- 加热和制冷都先走继电器
- 按键和蜂鸣器先预留

这样做最利于先完成硬件联调和软件编写。

## 7. 分版接线说明

当前建议默认按交流负载版联调；若执行器改为低压直流，请按低压版替换执行器接线。

### 7.1 交流负载版（默认）

- 加热：K1 继电器串联交流火线
- 制冷：K2 继电器串联交流火线
- 零线直通负载

### 7.2 低压直流版（扩展）

- 加热：HEAT_CTRL 驱动 MOS，负载走 DC_HEAT_V+ / DC_HEAT_GND_SW
- 制冷：COOL_CTRL 驱动 MOS，负载走 DC_COOL_V+ / DC_COOL_GND_SW
- 感性负载并联续流二极管
- 执行器大电流回路与传感器回路分区布线

## 8. 上电前核对清单

首版联调前建议逐项打勾：

- [ ] GPIO4、GPIO16 两路 DS18B20 上拉电阻均已安装
- [ ] OLED 地址与供电方式确认（0x3C 或 0x3D）
- [ ] GPIO18/19 控制输出与继电器输入一致
- [ ] 继电器模块供电与主控地共参考
- [ ] 按键接线为 GPIO 到地、软件上拉模式
- [ ] 蜂鸣器控制极性与模块规格一致
- [ ] 交流侧保险丝、漏保、隔离措施已就位
- [ ] 首次联调先用替代负载，不直接接大功率执行器

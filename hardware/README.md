当前文档默认对应的硬件平台为：

- ESP32-S3-DevKitC-1
- 16MB Flash
- 启用 QSPI PSRAM
- I2C OLED 使用 GPIO8/GPIO9
- 按键使用 GPIO12/GPIO13/GPIO14
- 蜂鸣器使用 GPIO15

当前建议优先补齐的硬件改进项：

- 加热链路独立硬件过温保护
- 交流负载版与低压直流版驱动分图
- 交流高低压隔离与保险丝/浪涌保护设计

## 下一步落地建议

建议先完成以下 4 项，再进入 PCB 打样：

1. 在交流版和低压直流版中二选一，按对应“实施稿”完成原理图
2. 固化端子定义（电源、探头、执行器、按键）并在图纸中统一网络名
3. 在原理图中明确加入硬件保护链（保险丝、热保护、浪涌吸收/续流）
4. 按 [硬件设计评审清单.md](%E7%A1%AC%E4%BB%B6%E8%AE%BE%E8%AE%A1%E8%AF%84%E5%AE%A1%E6%B8%85%E5%8D%95.md) 完成评审后，再进行联调

建议执行顺序：

1. 先读 [原理图设计.md](%E5%8E%9F%E7%90%86%E5%9B%BE%E8%AE%BE%E8%AE%A1.md) 的端子定义与保护参数
2. 选择实施路径：
	- 交流版：按 [原理图实施稿-交流版V1.md](%E5%8E%9F%E7%90%86%E5%9B%BE%E5%AE%9E%E6%96%BD%E7%A8%BF-%E4%BA%A4%E6%B5%81%E7%89%88V1.md)
	- 低压直流版：按 [原理图实施稿-低压直流版V1.md](%E5%8E%9F%E7%90%86%E5%9B%BE%E5%AE%9E%E6%96%BD%E7%A8%BF-%E4%BD%8E%E5%8E%8B%E7%9B%B4%E6%B5%81%E7%89%88V1.md)
3. 结合 [系统连接图.md](%E7%B3%BB%E7%BB%9F%E8%BF%9E%E6%8E%A5%E5%9B%BE.md) 做模块关系复核
4. 先执行 [硬件设计评审清单.md](%E7%A1%AC%E4%BB%B6%E8%AE%BE%E8%AE%A1%E8%AF%84%E5%AE%A1%E6%B8%85%E5%8D%95.md)，再按 [接线总表.md](%E6%8E%A5%E7%BA%BF%E6%80%BB%E8%A1%A8.md) 联调

如果你下一步要我继续画电路，我会直接把原理图相关文件放在这里。

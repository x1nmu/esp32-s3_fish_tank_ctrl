# 硬件设计评审清单（V1）

本清单用于在原理图冻结前做设计评审，覆盖交流版与低压直流版两条路线。

## 1. 通用项（必须）

- [ ] 主控、探头、OLED、按键、蜂鸣器引脚与固件一致。
- [ ] 网络命名统一（HEAT_CTRL、COOL_CTRL、TEMP_A、TEMP_B）。
- [ ] 传感器回路与大电流回路分区明确。
- [ ] 端子定义与接线文档一致，丝印清晰。
- [ ] 所有电源入口均有保险丝或等效保护。
- [ ] 存在明确的上电默认安全态（执行器默认断开）。

## 2. 交流负载版审查项

- [ ] 仅切火线，零线直通，不反接。
- [ ] 加热支路串联独立过温保护器与热熔断器。
- [ ] 继电器触点容量大于负载额定电流并留余量。
- [ ] 高压区与低压区保持足够电气间距。
- [ ] 交流入口具备浪涌吸收（MOV/RC 吸收）。
- [ ] 漏保、接地、防触电措施在系统层已定义。

## 3. 低压直流版审查项

- [ ] MOS 选型满足 3.3V 栅压下导通指标。
- [ ] 每路 MOS 均有栅极串联电阻和下拉电阻。
- [ ] 感性负载（风扇/泵）并联续流二极管。
- [ ] 功率地与控制地采用单点汇接策略。
- [ ] 大电流线宽满足热与压降要求。
- [ ] 功率器件预留散热路径和温升评估。

## 4. 系统联调前核对

- [ ] 空载上电，主控启动稳定，不反复复位。
- [ ] OLED 显示正常，按键输入正常。
- [ ] 探头双路采样均有效。
- [ ] HEAT_CTRL/COOL_CTRL 动作与端子输出一致。
- [ ] 带替代负载联调通过，再接入真实执行器。

## 5. 评审结论

- [ ] 通过（可进入 PCB 或打样）
- [ ] 不通过（需整改）

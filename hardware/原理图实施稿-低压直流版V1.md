# 100L 鱼缸温度控制器原理图实施稿（低压直流版 V1）

本文件用于指导低压直流执行器版本的原理图绘制，适用于：

- 直流风扇
- 低压 PTC 模块
- 低压循环泵
- TEC 实验模块（仅验证）

## 1. 图纸结构

建议采用 6 张子页：

- S1 电源输入与保护
- S2 主控与传感器
- S3 显示与按键
- S4 加热 MOS 驱动（DC_HEAT）
- S5 制冷 MOS 驱动（DC_COOL）
- S6 端子与接口

## 4. 分页连线清单

### 4.1 S1 电源输入与保护

- J1-1 -> F1 -> +5V_CTRL
- J1-2 -> GND
- +5V_CTRL -> U1 VIN/5V
- +5V_CTRL -> BZ1 VCC（按模块规格）
- U1 3V3 -> +3V3

执行器电源：

- J2-1 -> F2 -> DC_IN_V+
- J2-2 -> DC_PWR_GND
- DC_IN_V+ 与 DC_PWR_GND 之间并联 TVS1
- DC_PWR_GND 与 GND 单点汇接（靠近电源入口）

### 4.2 S2 主控与传感器

- U1-GPIO4 -> TEMP_A
- U1-GPIO16 -> TEMP_B
- U2-DQ -> TEMP_A
- U3-DQ -> TEMP_B
- R1: TEMP_A -> +3V3
- R2: TEMP_B -> +3V3
- U2/U3 VDD -> +3V3
- U2/U3 GND -> GND

### 4.3 S3 显示与按键

- U1-GPIO8 -> I2C_SDA -> U4-SDA
- U1-GPIO9 -> I2C_SCL -> U4-SCL
- U4-VCC -> +3V3
- U4-GND -> GND
- U1-GPIO12 -> KEY_SET（SW1 另一端接 GND）
- U1-GPIO13 -> KEY_UP（SW2 另一端接 GND）
- U1-GPIO14 -> KEY_DOWN（SW3 另一端接 GND）
- U1-GPIO15 -> BUZZ_CTRL -> BZ1-IN

### 4.4 S4 加热 MOS 驱动（DC_HEAT）

- U1-GPIO19 -> R11(100R) -> Q1-G
- Q1-G -> R12(10k) -> GND
- Q1-S -> DC_PWR_GND
- Q1-D -> DC_HEAT_GND_SW
- J4-1 -> DC_HEAT_V+（来自 DC_IN_V+）
- J4-2 -> DC_HEAT_GND_SW

若负载为感性（泵/风扇）：

- D1 并联在负载两端，阴极接 DC_HEAT_V+，阳极接 DC_HEAT_GND_SW

### 4.5 S5 制冷 MOS 驱动（DC_COOL）

- U1-GPIO18 -> R21(100R) -> Q2-G
- Q2-G -> R22(10k) -> GND
- Q2-S -> DC_PWR_GND
- Q2-D -> DC_COOL_GND_SW
- J5-1 -> DC_COOL_V+（来自 DC_IN_V+）
- J5-2 -> DC_COOL_GND_SW

若负载为感性（风扇/泵）：

- D2 并联在负载两端，阴极接 DC_COOL_V+，阳极接 DC_COOL_GND_SW

### 4.6 S6 端子与接口

- J3-1=+3V3
- J3-2=TEMP_A
- J3-3=TEMP_B
- J3-4=GND
- J4-1=DC_HEAT_V+
- J4-2=DC_HEAT_GND_SW
- J5-1=DC_COOL_V+
- J5-2=DC_COOL_GND_SW
- J6-1=KEY_SET
- J6-2=KEY_UP
- J6-3=KEY_DOWN
- J6-4=GND

## 5. MOS 选型建议

首版建议逻辑级 N-MOS，满足：

- 在 Vgs=3.3V 下有明确导通指标
- 连续电流和热阻有余量
- 封装便于散热（如 TO-252/TO-220/PowerPAK）

示例方向：

- AO4407A 同级别低压大电流器件（注意核对沟道类型）
- IRLZ44N 类逻辑级器件（体积大但调试方便）
- 实际以库存和热设计为准

## 6. 线宽与布局建议

- 执行器大电流回路单独走线，避免经过主控地回路。
- 传感器线、I2C 线远离 MOS 开关节点。
- Q1/Q2 附近预留散热铜皮与螺丝孔（如需外挂散热片）。
- 单点地汇接：控制地与功率地只在电源入口附近汇接。

## 7. 首次审图必查项

- TEMP_A/TEMP_B 两路上拉均已安装。
- Q1/Q2 栅极串联电阻与下拉电阻齐全。
- MOS 漏源方向与端子定义一致。
- 感性负载已加续流二极管（若为风扇/泵）。
- 执行器电源与控制电源地策略清晰（单点汇接）。
- 大电流网络名与端子丝印一致。
